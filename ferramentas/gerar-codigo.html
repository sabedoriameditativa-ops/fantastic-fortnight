Gerar código de acesso

Use esta página para criar os códigos que liberam a área premium. Ela funciona só no seu navegador; nada é enviado para a internet.

  1. Invente um código difícil de adivinhar (ou clique em "Sugerir").
  2. Clique em "Gerar" e copie a linha que aparecer.
  3. Cole a linha dentro de codeHashes: [ ] no arquivo config.js.
  4. Envie o código (não a linha gerada) para quem pagou.
