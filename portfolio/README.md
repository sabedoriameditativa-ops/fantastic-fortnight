## Executar as demonstrações

Baixe o repositório e abra um terminal na pasta `portfolio`. Com Python 3 instalado, execute:

```sh
python3 -m http.server 8000
```

Abra `http://localhost:8000`. O servidor local só serve os arquivos estáticos; não há instalação de dependências nem backend para estas demonstrações. O Frota Estelar usa o procedimento próprio no README da raiz.

Os formulários não enviam pedidos automaticamente. O contato comercial abre o WhatsApp para revisão e envio pelo visitante. A reserva da Casa Âmbar não é real e não salva os dados.

## Organização e limites

Esta pasta é uma cópia versionada dos projetos confirmados na conta atual do ChatGPT. Não inclui histórico de conversas, credenciais, documentos pessoais, arquivos fiscais ou banco de dados. Não foi concedida uma nova licença de uso dos códigos.

A integração é uma atualização pontual. Mudanças futuras feitas no ChatGPT não são copiadas automaticamente ao GitHub; é preciso solicitar nova sincronização.
